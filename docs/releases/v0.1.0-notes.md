**Status:** Ready for public tag `v0.1.0`. Definition of Done met on Linux operator verification; Spanish user guide mirror complete. Optional P2 screenshots (`seerr-request` / `jellyfin-library`) may follow later.

## Highlights

- Modular Compose stack with `FLIXBOX_MODE` Direct/VPN dual-mode
- `bin/flixbox` — `init`, `up`, `configure`, `reload`, `status`, `vpn-test`, `credentials`, …
- API-assisted first-run (`configure`); indexers and Maintainerr rules stay manual
- LAN access profiles: `trusted` (default) / `shared` (Forms + localhost admin bind) — [ADR 0015](../adr/0015-access-profiles.md)
- `FLIXBOX_PUBLIC_HOST` syncs Homepage LAN hrefs, `HOMEPAGE_ALLOWED_HOSTS`, and empty `JELLYFIN_PUBLISHED_URL`
- Jellyfin `LocalNetworkAddresses` `::` footgun cleared by `configure`
- Full Spanish user guide mirror (`docs/es/user/`) + lawful-use disclaimer EN/ES
- Pinned image tags — [14 — Image pins](../user/14-image-pins.md)

## Upgrade / first install

```bash
git clone https://github.com/aleaz/flixbox.git
cd flixbox
cp .env.example .env
# Edit DATA_DIR, CONFIG_DIR, FLIXBOX_MODE, TZ; optional FLIXBOX_ACCESS_PROFILE=shared
# Optional LAN: FLIXBOX_PUBLIC_HOST=192.168.x.x
./bin/flixbox init --non-interactive
./bin/flixbox up
./bin/flixbox configure
```

Shared Wi‑Fi: `./bin/flixbox credentials set arr-ui --generate` — [Access profiles](../user/13-access-profiles.md).

## Known limitations

- Optional P2 UI story stills (`docs/images/en/seerr-request.png`, `jellyfin-library.png`) not required for tag
- Remote / WAN access not in scope (no env switch)
- No “Forms + LAN publish” profile yet (password on Wi‑Fi without localhost-only bind) — roadmap v0.4
- Servarr Forms users are not seeded by `configure` (use `credentials set arr-ui` under `shared`)
- Caddy `proxy` profile is LAN-oriented; do not publish to WAN without additional auth
- Release workflow runs Trivy CRITICAL as a **report** (non-blocking): upstream Decluttarr/Homepage/etc. images still ship OS/npm CRITICAL CVEs Flixbox cannot patch; `.trivyignore` tracks known Homepage tar CVE until the next pin
